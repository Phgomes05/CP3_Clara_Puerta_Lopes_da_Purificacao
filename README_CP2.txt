CP2 — SITE PESSOAL / PORTFÓLIO
=================================

Projeto evoluído a partir do CP1 para atender aos requisitos de responsividade.

PÁGINAS
-------
- index.html
- curriculo.html
- formulario.html
- multimidia.html
- graficos.html

RECURSOS
--------
- estilo.css
- img/programacao.svg
- audio.ogg
- video.mp4

REQUISITOS ATENDIDOS
--------------------
[OK] Meta viewport em todas as páginas.
[OK] Flexbox no cabeçalho/menu.
[OK] Flexbox em seção de conteúdo (lista de interesses e opções).
[OK] Grid no currículo, com 1 coluna no mobile e 2 no desktop.
[OK] Grid no formulário, com 1 coluna no mobile e 2 em telas maiores.
[OK] Media queries mobile-first usando min-width.
[OK] Media queries específicas para index.html e curriculo.html.
[OK] Imagens e vídeos com max-width: 100% e height: auto.
[OK] Área de toque mínima de aproximadamente 44px em links/botões.
[OK] Navegação igual em todas as cinco páginas.
[OK] CSS sem media query max-width como abordagem principal.
[OK] Conteúdo não é removido no mobile.

TESTE
-----
No navegador, abra index.html e use Ctrl + Shift + M.
Teste pelo menos:
- 320 px
- 768 px
- 1024 px

Confira principalmente:
- menu;
- currículo em uma/duas colunas;
- formulário em uma/duas colunas;
- áudio e vídeo;
- SVG;
- ausência de rolagem horizontal.

OBSERVAÇÃO
----------
A pasta extras/ contém o arquivo arena.html e sua imagem SVG original,
preservados do material enviado, mas eles não fazem parte da navegação
principal do CP2.
