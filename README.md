# Site Pessoal / Portfólio — CP3

Projeto acadêmico evoluído a partir do CP2. Site estático com cinco páginas interligadas.

## Páginas
- `index.html` — apresentação e interesses
- `curriculo.html` — formação e experiência
- `formulario.html` — formulário validado com armazenamento local
- `multimidia.html` — áudio e vídeo
- `graficos.html` — desenho em Canvas e SVG

## Estrutura
- `css/estilos.css` — estilos responsivos
- `js/scripts.js` — interatividade, validação, Canvas e localStorage
- `img/` — imagens do projeto
- `audio.ogg` e `video.mp4` — arquivos multimídia

## Recursos CP3
1. Alternância entre tema claro e escuro, com preferência salva em `localStorage`.
2. Formulário com validação HTML/JavaScript e feedback acessível.
3. Mensagens demonstrativas salvas no `localStorage`, listadas na página e com opção de exclusão.
4. Gráfico Canvas desenhado por JavaScript.

**Privacidade:** o formulário é uma demonstração front-end. Os dados são armazenados apenas no navegador atual e não são enviados a um servidor ou e-mail. Evite inserir informações sensíveis.

## Executar localmente
Abra `index.html` em um navegador. Para testar como um site hospedado, use a extensão Live Server do VS Code ou outro servidor HTTP local.

## Publicar no GitHub Pages
1. Crie um repositório GitHub vazio.
2. Envie os arquivos desta pasta para a branch `main`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Aguarde a publicação e confirme que o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/` abre em janela anônima.
5. Confira individualmente as cinco páginas e os arquivos de áudio/vídeo.
